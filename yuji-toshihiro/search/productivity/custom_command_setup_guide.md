# カスタムコマンド設定方法の詳細ガイド

## 📱 設定場所の違い

### 1. **Supervisporアプリ内での設定**
Supervisporのカスタムコマンドは**Supervisporアプリ自体**で設定します。

```
設定手順：
1. Supervisporアプリを開く
2. 設定メニュー → カスタムコマンド
3. 新規コマンドを追加
4. コマンド名（例: "nt"）と動作を設定
```

### 2. **ショートカットアプリ（iOS）の役割**
ショートカットアプリは**補助的な自動化**のために使用：

```
用途例：
- Supervisporを経由せずに直接Notionを開く
- 複数のアプリを連携させる
- 条件分岐を含む複雑な処理
```

## 🔧 具体的な設定例

### Supervisporでの設定
```yaml
コマンド: "nt"
動作: URLを開く
URL: notion://www.notion.so/[your-todo-page-id]
```

### ショートカットアプリでの設定（オプション）
```yaml
ショートカット名: "Notion ToDo開く"
動作:
  1. NotionアプリのToDoページを開く
  2. 今日の日付でフィルター
  3. 通知を表示
```

## 💡 使い分けのポイント

| 機能 | Supervispor | ショートカット |
|------|------------|--------------|
| 簡単なURL開く | ◎ 推奨 | ○ 可能 |
| テキスト入力 | ◎ 推奨 | △ 複雑 |
| 複数アプリ連携 | △ 制限あり | ◎ 推奨 |
| 条件分岐 | × 不可 | ◎ 推奨 |
| ウィジェット | ◎ 推奨 | ◎ 推奨 |

## 🎯 推奨設定

### 基本的なコマンドはSupervisporで
- "nt" → Notion ToDo開く
- "nta" → 新規タスク追加
- "ntd" → 今日のタスク

### 複雑な処理はショートカットで
- 時間帯によるビュー切り替え
- 他アプリとの連携
- バックグラウンド処理

つまり、**カスタムコマンドはSupervisporアプリ内で設定**し、必要に応じてショートカットアプリで補完する形が最適です。
