# Superwhisper × Notion ToDo 連携ガイド

## 🎤 Superwhisperとは
音声をテキスト化し、AIで整形してくれる音声入力アプリ

## 📱 Notion ToDoへの効率的な追加方法

### 方法1: コピー&ペースト方式
1. **Superwhisperで音声入力**
   ```
   例: "今日の会議資料を作成する、締切は金曜日"
   ```

2. **AIで整形されたテキストをコピー**
   - Superwhisperが自動的に句読点や改行を追加
   - より読みやすい形式に変換

3. **Notionアプリを開いてペースト**
   - ToDoデータベースに直接ペースト
   - またはクイックキャプチャに貼り付け

### 方法2: 共有機能を活用
1. **Superwhisperで音声入力**
2. **共有ボタンをタップ**
3. **Notionを選択**（共有先として）
4. **保存先を選んで追加**

### 方法3: ショートカットアプリ連携（iOS）
```yaml
ショートカット設定:
1. Superwhisperからテキストを受け取る
2. Notion APIでToDoデータベースに追加
3. 完了通知を表示
```

### 方法4: メモアプリ経由
1. **Superwhisper → メモアプリ**に自動保存設定
2. **メモアプリとNotionを同期**
3. 定期的にメモからNotionへ移動

## 🚀 効率化のコツ

### 音声入力のテンプレート
```
"タスク: [内容]、期限: [日付]、優先度: [高/中/低]"
```
このように話すと、Superwhisperが構造化されたテキストに変換

### よく使うフレーズを登録
- "今日中に" → 期限: 今日
- "急ぎで" → 優先度: 高
- "来週までに" → 期限: 来週金曜日

### バッチ処理
複数のタスクをまとめて音声入力：
```
"1つ目、資料作成。2つ目、メール返信。3つ目、会議準備。"
```

## 💡 実践的なワークフロー

### 朝の計画
1. Superwhisperを起動
2. 今日のタスクを一気に音声入力
3. 整形されたリストをNotionにコピー
4. Notionで優先順位を調整

### 移動中のタスク追加
1. イヤホンのマイクでSuperwhisper起動
2. 思いついたタスクを話す
3. 後でまとめてNotionに転記

### 会議後の整理
1. 会議で決まったアクションアイテムを音声入力
2. AIが箇条書きに整形
3. Notionのプロジェクトページに追加

## 🔧 設定の最適化

### Superwhisper側の設定
- **言語**: 日本語
- **句読点**: 自動追加ON
- **改行**: 自動判定ON
- **AIモデル**: タスク管理に最適化

### Notion側の準備
- **クイックキャプチャページ**を作成
- **ToDoテンプレート**を用意
- **モバイルビュー**を最適化

## ⚡ トラブルシューティング

### よくある問題
1. **文字化けする場合**
   - 文字コードをUTF-8に統一
   - コピー時の形式を確認

2. **改行が反映されない**
   - プレーンテキストでコピー
   - Notionの設定でマークダウンを有効化

3. **音声認識の精度が低い**
   - 静かな環境で録音
   - はっきりと発音
   - 専門用語は事前に辞書登録
