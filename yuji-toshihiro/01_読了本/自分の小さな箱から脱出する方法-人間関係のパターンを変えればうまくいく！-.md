# 自己欺瞞
- 自分を欺くこと=箱の中に囚われている状態
	- 自分自身の問題に気づかない
	- ウィーン病院での細菌という`見えない問題`による死亡者の増加
# 人間の察知力
- 人間は、相手が自分に対して何を思っているかを感じられる
	- 謝る気のない謝罪
	- 関心のない質問
- 重要なのは、外見上何をしているかではなく、心の中でその人のことをどう思っているか
	- 同じ行動をしたとしても、`箱の中にいる状態`で行うのと`箱の外にいる状態`で行うのとでは受け取り手の感じ方が180度変わってしまう
# 自分への裏切り
1. 自分が`するべき`と思った感情を裏切る
2. 周りの世界を自分への裏切りを正当化する視点から物事を見るようになる
3. 現実を見る目が歪む
4. 箱に入る
5. 時が経つにつれて、いくつかの箱を自分の性格とみなすようになり、それを持ち歩くようになる
6. 他の人も箱の中に入れる
7. 違いに相手を酷く扱い、箱の中にいる口実をより多くつくってしまう
# 箱の中にいる時にしても無駄なこと
1. 相手を変えようとすること
2. 相手と全力で張り合うこと
3. その状況から離れること
4. コミュニケーションを取ろうとすること(相手を責める気持ちは隠せない)
5. 新しいテクニックを使おうとすること
6. 自分の行動を変えようとすること

# 考えたこと
- `箱`の定義
	- 自他を分けて考える意識
	- 自分の所属するグループと他のグループの`壁`
		- 例１：開発チームと営業チーム
			- 振る舞い：開発チームのミスはカバーしようとするが、営業チームの無理な開発要求やミスには容赦がない
				- あるべき姿：どちらも企業の成長のために働いているのだから、壁の外にで公平な立場で考えるべき
		- 例２：自社と競合会社
			- 振る舞い：他社の成長を妬み、失敗を喜ぶ
				- あるべき姿：同じような世界を目指しているのだから、健全な競争関係を築くべき。他社の成長は妬むものではなく、自分に刺激を与えてくれるものと捉える
- 箱の外に出るには`自分以外の人の意見に考えを巡らせる`
	- 例
		1. 同僚がどんな問題にあたっているのか考えてみる
		2. 電車の中で、周りにいる人は何を考えているのか想像してみる
			- 本筋：本書は人間関係についてメインに書かれている
				- ビジネスアイディアを絞り出すには、箱の外に出る必要がある
- 感情のコントロールに使える
	- 怒り：自分の期待を裏切られた時に湧き上がる
		- 箱の応用：他人の立場を、自分に置き換えて考えれば何かしら理由が見えてくる
			- 例：ミスばかりする同僚
			  ->やり方がわからない/プライベートで色々と問題があった
				- 同僚が持つ問題を探ってみる
