### Highlights & Notes

- 「UI」と「それ以外」を区別していない
- ![](https://assets.st-note.com/img/1695129932016-B6nVBGzCJb.jpg?width=1200)
- 広大に広がるゲームの中の世界の上に、画面という一枚の透明な板が敷いてあり、プレイヤーにしか見えない操作板が乗っかっているような構造
  - Notes: ゲームを作る人も、遊ぶ人も、大多数は「それでいい」と思っているはずです。疑問も持たず、考えたことすらないかもしれません。
- UI（の役目をするもの）が、キャラクターや地形と同じレイヤーに存在している
- 正確に言えば、レイヤーを行き来できている
- モンスターの王様・アズゴアは、武器で「みのがす」コマンドを破壊してしまいます。
- 「我々には戦う道しかない」という意思表示をするための演出
- ゲームを進めようという決意。それに伴う、選択と決断をする力。
- 「Determination（日本語版：ケツイ）」をテーマ
- このリアル絵で「その❤️はね キミのタマシイさ」は絵柄が違いすぎて通用せんのよ
- ①「透明な板」の存在を知覚してUIを作る
- ドロップシャドウのつけすぎに注意
- 「透明な板」の上にたくさんのものが置いてあることで、板の存在をユーザーがなんとなく感じ取れるようになってしまいます
- ②「操作する」ということの意味を決める
- 「このゲームにおいて『操作する』とはどういうことか」ということを否が応でもユーザーに強く考えさせるストーリーがあり、それに合ったアートスタイルや演出が用意
- （魚を釣ったときの主人公のセリフが「心の中でふざけただけ」に見える表現なのがかなり上手いです）
