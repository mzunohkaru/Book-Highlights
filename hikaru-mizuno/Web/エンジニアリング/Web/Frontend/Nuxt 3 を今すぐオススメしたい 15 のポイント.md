#### Highlights & Notes

> setup内で呼び出せる useFetch や useAsyncData だけでなく、$fetch という汎用的なAPIも提供されており、この自動型推論は $fetch でも機能するので、axiosのような感覚で使う

> API Routes 機能で実装した関数の返り値に自動で型が付く

> 単に記述量が減るだけでなく、ランタイムパフォーマンスが向上する、defineProps/defineEmits（後述）が使えるなど、基本的にはメリットしかない記法

> 圧倒的に簡潔に書ける <script setup> 記法
