#### Highlights & Notes

> 内部に含まれるコンテンツをクライアントサイドでのみレンダリングするための仕組み

> ClientOnly コンポーネント

> ClientOnly 内のコンテンツはサーバーサイドビルドから完全に除外されます

> クライアント固有の機能（ブラウザの API を利用するコンポーネントや、重いライブラリを使った UI など）は、初期の SSR に含めると不整合やパフォーマンス問題が発生する

> ClientOnly を利用することで、クライアント側に切り替わった後にのみこれらのコンポーネントを安全にマウントする

> <ClientOnly fallback-tag="span" fallback="Loading comments...">

> 例2: スロット #fallback を使ったより柔軟なフォールバック

> 具体的なユースケースとコード例

> DevOnly コンポーネント

> 開発中のみ必要なコンテンツを表示するためのコンポーネント
