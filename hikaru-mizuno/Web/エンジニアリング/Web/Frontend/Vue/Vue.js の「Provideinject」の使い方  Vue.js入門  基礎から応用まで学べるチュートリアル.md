#### Highlights & Notes

> provide/inject は、あるコンポーネントが自分の子孫に対してデータや関数を渡す仕組み

> アプリ全体で共通の設定値やテーマカラー、認証情報など、複数のコンポーネントで使いたいデータを一箇所から管理でき

> inject 関数を使って「themeColor」というキーで提供された値を取得

> 値を作成し、provide 関数でキー「themeColor」として提供
