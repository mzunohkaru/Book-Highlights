> Atoms

> 特定のプロダクト (Webサイト) についての知識を持たない基本的な Web UI としての知識 (機能) しか持たない

> ボタンやフォームはサービスなどに一貫して定義されたデザインに沿ったもの

> どのようなプロダクトにも利用できるし、利用するべき

> Molecules

> 自分が検索ボタンとして使われるか、フォームの確定ボタンに使われるかなどは知りません

> 特定のプロダクト (Webサイト) についての知識を持たないいくつかのコンポーネントを組み合わせて構成されるような Web UI の知識 (機能) を持ついくらかの複雑性はもつがこれ単体では成立しない

> Organisms

> 特定のプロダクト (Webサイト) についての知識を持つそれ単体で Web サイト内で存在できる

> ![](https://storage.googleapis.com/zenn-user-upload/e7iulkvaze90l0kid5zsw6rk4a1j)

> コンポーネントは特定のプロダクトの知識を十分に有しているため、他のプロダクトではこのヘッダーコンポーネントは利用できません。

> 知識をもたせることができるので、プロダクト特有のWeb API をコールさせても良い
