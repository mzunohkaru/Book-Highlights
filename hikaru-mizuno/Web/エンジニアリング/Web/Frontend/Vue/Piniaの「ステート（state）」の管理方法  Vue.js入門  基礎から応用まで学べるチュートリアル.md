#### Highlights & Notes

> ステートとは、アプリケーションが保持するデータ

> 複数のコンポーネントで共有して使いたいデータがステート

> 関数として定義することで、サーバーサイドレンダリング（SSR）とクライアントサイドの両方で正しく動作する

> Setup Storeでの型定義

> ステートへのアクセス方法

> ストアはリアクティブなオブジェクト

> 注意点として、ステートには、初期状態で定義されていないプロパティを後から追加することはできません。

> ステートのリセット

> $resetメソッドを定義する

> ステートの変更方法

> 1. stateを直接変更する

> 2. $patchメソッドを使用（オブジェクト形式）

> 複数のステートプロパティを一度に変更したい場合

> ステートプロパティに直接値を代入する

> 3. $patchメソッドを使用（関数形式）

> より複雑な変更を行う場合は、$patchメソッドに関数を渡す

> ステートの監視（Subscribe）

> 複数の変更が1つのトランザクションとして扱われるため、デバッグツールでの追跡がしやすく

> アプリケーションの状態が変更されたときに特定の処理を実行したい場合

> たとえば、ステートをローカルストレージに保存したり、ログを記録したりするケース

> $subscribeメソッドを使ってステートの変更を監視できます。

> 監視のオプション

> $subscribeメソッドには、第二引数としてオプションを指定でき

>   detached: true, // コンポーネントがアンマウントされても監視を続ける  flush: 'sync'   // 同期的に実行する（デフォルトは 'pre'）
