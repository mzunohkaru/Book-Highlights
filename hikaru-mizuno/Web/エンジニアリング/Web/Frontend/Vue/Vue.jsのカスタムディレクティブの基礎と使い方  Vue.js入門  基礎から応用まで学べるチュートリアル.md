#### Highlights & Notes

> カスタムディレクティブ

> あなた自身が作成するディレクティブ

> 「HTMLの要素を直接操作するための特別な指示」

> バインディングの情報

> カスタムディレクティブのフックに渡されるbindingオブジェクト

> value: ディレクティブに渡された値arg: 引数（v-my-directive:fooのfoo部分）modifiers: 修飾子（v-my-directive.bar.bazの{ bar: true, baz: true }）oldValue: 前回の値（beforeUpdateとupdatedでのみ利用可能）
