#### Highlights & Notes

> 「一方向データフロー」という設計思想

> データの流れを予測しやすく、バグを減らすための重要な考え方

> 一方向データフローでは、親から子へのデータの流れは明確（propsを通じて）ですが、子から親へのデータの流れも制御する
