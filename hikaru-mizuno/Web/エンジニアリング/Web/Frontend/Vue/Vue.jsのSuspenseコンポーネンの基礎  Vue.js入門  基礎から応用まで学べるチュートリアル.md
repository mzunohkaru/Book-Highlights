#### Highlights & Notes

> Suspense の基本

> 非同期コンポーネントが読み込み中の状態であっても、アプリケーションのUXを損なわないよう、代わりに一時的なコンテンツ（プレースホルダー）を表示するために使用

> Suspenseは、非同期コンポーネントだけでなく、非同期データ取得にも利用できます。

> fallbackスロットにスケルトンスクリーンを設定

> データが読み込まれるまで、fallbackスロットに指定した「データをロード中」のテキストが表示
