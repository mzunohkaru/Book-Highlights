#### Highlights & Notes

> なぜコンポーネントの v-model が必要なのか？

> データの入力や編集を扱うコンポーネントでは、この往復（props down, events up）を毎回手動で書くのは面倒

> defineModelを使った実装方法

> :first-nameと:last-nameという2つの異なる属性に対してv-modelを使って

> 子コンポーネント側ではdefineModel('firstName')とdefineModel('lastName')で、それぞれのモデルを定義
