#### Highlights & Notes

> トランジション機能は、要素の表示・非表示をアニメーションで演出できる便利な機能

> アニメーションを適用したい要素を <transition> タグで囲み

> name属性（上の例ではsimple）に基づいて自動的に6つのCSSクラスが適用されます。

> トランジションのクラス

> 表示される時:simple-enter-from: 最初の状態simple-enter-active: アニメーション中の状態simple-enter-to: 最終的な状態非表示になる時:simple-leave-from: 最初の状態simple-leave-active: アニメーション中の状態simple-leave-to: 最終的な状態

> トランジションのイベントフック

> 表示時:@before-enter: 要素が挿入される前@enter: 要素が挿入された直後@after-enter: アニメーション完了時@enter-cancelled: アニメーションがキャンセルされた時非表示時:@before-leave: 非表示アニメーション開始前@leave: 非表示アニメーション開始時@after-leave: アニメーション完了時@leave-cancelled: アニメーションがキャンセルされた時
